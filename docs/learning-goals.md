## Jogo dos Pares

- **Objectives:** Practice sustaining attention while looking across the two card groups, and reasoning about relationships between objects and pictures.
- **Mechanics:** Each theme has five different rounds of six related pairs. The child looks across both groups and matches related pictures by dragging or selecting one card from each side. Naming the match makes the relationship explicit; a brief visual confirmation and optional gentle sound acknowledge the match. Incorrect choices do not remove progress, so the child can keep trying.
- **Themes:** Princesses, home, animals, transport, food, and garden.
- **Difficulty:** One fixed level with six pairs (12 cards). The selected theme stays the same through the session, while each round uses a different set of pairings.
